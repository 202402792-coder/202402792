# 오늘 뭐 먹지? — 대학생 점심 메뉴 추천 웹앱

프로젝트관리론 수업의 **바이브 코딩 실습 수준**으로 제작한 간단한 정적 웹앱입니다. 사용자가 음식 종류를 고른 뒤 메뉴를 추천받고, 마음에 드는 메뉴를 저장할 수 있습니다.

## 실행 방법
1. ZIP을 풀거나 GitHub 저장소 파일을 다운로드합니다.
2. `index.html`을 Chrome, Safari 등 브라우저에서 엽니다. (CSS·JS 파일을 같은 폴더에 둡니다.)
3. 음식 종류 선택 → 추천받기 → 다시 추천 → 메뉴 저장·삭제를 시도합니다.

정적 웹사이트로 설계했으므로 서버, 설치 패키지, 계정은 필요하지 않습니다. 배포 후에는 GitHub Pages URL로 접속할 수 있습니다.

보류: REQ-06 예산별 추천, REQ-07 주변 실제 식당 조회.

## 주의사항
- 메뉴 데이터는 미리 작성한 예시이며 실제 식당의 가격·영업시간·위치 정보가 아닙니다.
- 저장한 메뉴는 **브라우저별**로 보관됩니다. 다른 기기와 자동 동기화되지 않습니다.
- 이 프로젝트의 사용자 분석은 가상 페르소나에 기반했으며, 인터뷰·설문 결과는 아닙니다.

## 검증 안내
- Chromium 기반 UI 조작 테스트 16개가 통과했습니다. 다만 저장소 테스트는 모의 localStorage이며 실제 브라우저 새로고침 유지 여부는 아직 미확인입니다.
- 배포 후 [브라우저 저장 검증](./verify.html)을 실행하고, 웹앱에서 직접 메뉴 저장→새로고침→삭제→새로고침을 확인해 `07_check.md`에 실제 결과를 기재하세요.

## GitHub Pages 배포 방법
1. 사용자가 지정한 **Public 저장소 `202402792-coder/202402792`**에 올립니다. 앞선 과제 저장소는 변경하지 않습니다.
2. 이 폴더의 파일을 저장소 **최상위 경로**에 올립니다. `index.html`이 최상위에 있어야 합니다.
3. **Settings → Pages → Deploy from a branch → main → /(root) → Save**로 설정합니다.
4. 제공된 공개 URL을 직접 열어 브라우저 저장·재접속까지 확인합니다.
5. `07_check.md`에 배포 후 검증 결과를 보완한 뒤 제출합니다.
